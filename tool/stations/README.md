# Station import

Loads `gas_stations_northern_mindanao.json` (Google Places export: Cagayan
de Oro, Iligan, Ozamiz, Oroquieta) into Firestore.

What it writes:

- `stations/{placeId}` — one document per station with name, brand, address,
  coordinates, amenities, hours, phone, website, rating. Price reports keep
  merging prices into these documents.
- `directory/stations` — one document with a compact entry for every station.
  The app reads this single document to paint the map (one read, one
  listener). Entry keys are documented in `lib/models/station_directory.dart`.

Permanently closed stations are skipped. `Independent / other` becomes an
empty brand so the station's own name shows.

## Run

```sh
cd tool/stations
npm install
npm run dry-run                       # transform only; writes out/preview.json

# Real import, pick one way to sign in:
node import_stations.mjs --cli-login --check         # sign-in test, reads only
node import_stations.mjs --cli-login                 # reuses `firebase login`
node import_stations.mjs --key ../../serviceAccount.json
```

`--cli-login` hands the Firebase CLI's login to the Admin SDK as a
temporary Application Default Credentials file (deleted on exit), because
Firestore's client refuses a bare refresh token.

A service-account key comes from Firebase console → Project settings →
Service accounts → Generate new private key. Never commit it (the
`.gitignore` covers `*serviceAccount*.json`).

Re-running is safe: documents are merged, so reported prices survive.

`sample_directory.json` is regenerated by every run and decoded by
`test/models/station_directory_test.dart`, so the app and this script can't
drift apart. Commit it when the format changes.
